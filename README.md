# Frontend - Programação Frontend (Next.js / React / Tailwind CSS)

Interface web moderna construída com **Next.js 15+ (App Router)**, **React 19**, **TypeScript** e **Tailwind CSS**, desenvolvida para a cadeira de Programação Frontend e integrada ao projeto **PI3**.

## 🚀 Tecnologias
- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- Docker

## 🛠️ Como Executar Localmente

### Pré-requisitos
- Node.js 20+ instalado (ou Docker)

### Com npm:
```bash
npm install
npm run dev
```
Acesse: [http://localhost:3000](http://localhost:3000)

## 🐳 Com Docker
```bash
docker build -t pi3-frontend .
docker run -p 3000:3000 pi3-frontend
```
